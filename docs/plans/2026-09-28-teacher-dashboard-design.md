# 教师后台重构设计

教师登录页与工作台分离：`/teacher/` 只负责登录，成功后进入 `/teacher/dashboard/`。工作台采用固定左侧导航和右侧内容区，将现有能力整理为首页、班级与学生、课程与课题、作品审核、家长交付、招生咨询、网站内容七个模块。

首页只承担决策与导航，不放长表单。它展示待审核、新咨询、分享中未公开、已发布四项指标，以及作品状态分布、招生咨询漏斗、今日待办、快捷操作和近期活动。其余模块使用列表加详情、筛选工具栏和对话框完成具体操作。

现有课程、课题、班级、学生、作品、咨询、内容管理接口继续沿用。新增教师登录、会话检查和退出接口，通过 HttpOnly、SameSite 会话 Cookie 支持跨页面登录；原有 `X-Admin-Token` 继续保留给部署脚本和兼容调用使用。管理密码不写入前端源码、网址、Git 或浏览器本地存储。

视觉方向为“清晰的教学运营控制台”：深墨蓝侧栏、明亮纸张式工作区、珊瑚色重点操作与蓝色数据图表。桌面端保持高信息密度，移动端侧栏变为抽屉，表格允许局部横向滚动但页面本身不产生横向溢出。
