# 课堂在线收件与发布（正式班使用）

## 课前：建班和分发编号

1. 老师双击项目根目录的 `打开教师工作台.command`，它会打开[教师工作台](https://www.codexai.site/teacher/)并把教师密钥复制到剪贴板；在网页中粘贴登录。密钥原件在本机 `preparation/.teacher-admin-token`，不要发送给学生，也不要放进 PPT 或 GitHub；换电脑时需安全迁移密钥和 SSH 私钥。
2. 创建一个新的班级编号，例如 `c260924a`，填写人数。系统自动生成 `c260924a-s01` 等独立作品编号和每人不同的上传码。不同班级不能重复使用编号。
3. 点击“下载编号与上传码名单”，在老师自己的副本中填写孩子与家长的对应关系。只把各自的一组编号、上传码发给对应孩子；学生账号不记录真实姓名；网站咨询表单的家长联系方式另存于日本 VPS 的教师后台，不进入作品展。
4. 预先在学生电脑打开 [下载页](https://codexai.site/classroom/) 和 [提交页](https://codexai.site/classroom/submit/)，检查网络和 ZIP 下载。

## 课中：孩子提交，老师发布

1. 孩子下载通用起始包，解压后在 TRAE 中改项目，在本机浏览器测试。需要提交时，把**整个项目文件夹**压成 ZIP；ZIP 名字可以随意，系统按输入的作品编号归档。
2. 孩子在提交页输入自己的编号和上传码，选择 ZIP 并上传。服务器会检查压缩包体积、文件类型、目录与必需文件；失败会在页面显示原因，孩子可修改后重交。
3. 教师工作台点“刷新全班状态”。对“待审核”作品点“打开隔离预览”，确认标题、记账、预算、刷新等正常，并检查没有真实姓名、家庭账目、外部追踪或不合适内容。预览使用不同浏览器域名，与家长正式作品分开；自动检查不能代替功能和内容验收。
4. 有问题点“退回修改”，填写具体原因；孩子点“查询我的进度”看到原因，改好后重新上传。通过的作品点“确认发布”；这一步才把新版本切换到难猜测的 `https://codexai.site/share/…/` 家长专属链接；不会自动进入公开作品展。
5. 老师从对应行复制家长链接或显示二维码。孩子提交页点“查询我的进度”也会出现已发布链接和二维码。发到家长自己手机时直接发可点击链接；二维码适合印在纸上或用另一块屏幕展示。不要公开展示全班编号与上传码名单。

## 家长保存到手机桌面

家长先联网用 Safari（iPhone）或系统浏览器/Chrome（安卓）打开专属链接，等页面显示“离线页面已准备好”，再添加到主屏幕。从桌面图标重新打开，记一笔练习记录，关闭重开并开飞行模式复测。手机账目只在这部手机的该浏览器/桌面环境保存，不会同步到 VPS；请定期导出 JSON 备份，换手机时导入。

## 长期保留与故障处理

- 每次上传的原 ZIP、待审核文件、已发布历史版本都留在 VPS，不自动过期。重新提交和重新发布沿用同一网址；老师拒绝新版本时，家长当前版本仍能访问。
- 课后双击项目根目录的 `一键备份课堂作品.command`，把服务器数据库、原 ZIP 和所有版本下载到本机 `backups/`。脚本会校验压缩包；再把备份复制到老师自己的另一处长期存储。手机里的真实账目不在此备份中。
- 服务器异常时可看 `sudo systemctl status codexai-uploader` 和 `sudo journalctl -u codexai-uploader -n 100`；公开网站由 Caddy 提供。[手动发布脚本](../scripts/deploy-student.sh)仍通过同一上传与审核接口；若整个接口不可用，此脚本也不能发布。
- 如果只有老师一人带班，尽早让完成的孩子提交，边讲边审核。下课前可先让家长在孩子电脑上看本地成品；已审核发布的作品再交手机链接。

正式班前仍需用实际学生电脑、课堂网络、家长 iPhone 和安卓手机各彩排一次。电脑浏览器通过不能代替真实手机“添加桌面”验收。
