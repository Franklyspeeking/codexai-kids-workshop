# 课堂项目使用方法

starter 是学生起点：可记账，愿望和预算模块已保留可靠底层逻辑，但默认隐藏。孩子通过Prompt让AI启用并按自己的需求修改。这是明确公开的教学脚手架，不宣称从空白独立编写。
standard 是完整救援版：功能齐全，供老师恢复进度，孩子仍须完成自己的规则与测试。

每名学生在 https://codexai.site/classroom/ 下载同一份starter压缩包，解压整个项目文件夹，不只复制money子目录。老师在收件和发布时按作品编号设置唯一的config.js存储ID；正式发布后不要改编号或ID。
打开复制的项目文件夹，用工具自带本地HTTP预览，入口为money/index.html。若电脑已有Python，可在项目根目录运行 python3 -m http.server 8080 ，浏览器访问 http://localhost:8080/money/ 。工具若提供预览服务器可直接使用，不必让孩子安装额外环境。

第一轮修改config.js默认文案；第二轮找到wish-module和budget-module，移除hidden并完善其行为和说明；第三轮修改一项触发规则。使用浏览器设置区调整值是体验产品，真正课堂制作至少要通过AI修改项目文件。

默认值只在空账本首次初始化时生效；已有记录会保留。测试新默认值请先备份，再清空自己的练习账本。家长新设备首次打开读取的是发布文件中的默认值。

`money/sw.js`负责离线页面缓存。孩子可以修改页面和规则，但不要删除它；若新增本地图片等资源，首次联网打开页面后也应在飞行模式下复测。手机浏览器可能清理缓存和账本，离线功能不能代替导出备份。
