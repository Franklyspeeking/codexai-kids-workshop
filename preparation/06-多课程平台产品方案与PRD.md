# 儿童 AI 创作平台｜产品方案与 PRD（第一版）

## 目标与边界

把当前一次性的“下载—交作业—发布”扩展为可持续的课程平台。一个孩子沿用同一个作品编号和上传码参加多个主题；半天工作坊和 6–8 天营期使用同一套课程结构。每个主题可多次提交，老师验收后发布新版本；公开网站展示老师确认公开的作品。第一版只托管静态网页，不执行学生服务器程序，不收孩子真实姓名、学校、家长电话或真实账目。

## 信息架构

| 区域 | 地址 | 主要内容 |
|---|---|---|
| 公开网站 | `codexai.site` | 工作坊介绍、课程方向、作品展、每个已发布作品 |
| 教师后台 | `www.codexai.site/teacher/` | 班级、项目/营期、课题、分配、提交审核、公开展示开关 |
| 学生后台 | `www.codexai.site/student/` | 登录、我的课程与课题、下载起始包、提交新版本、查看反馈与作品链接 |
| 隔离预览 | `codexai.site/preview/…` | 待审核静态作品的临时预览；不带师生登录状态 |

旧 `codexai.site/works/编号/money/` 地址继续保留；新通用课题使用 `codexai.site/projects/编号/课题代号/`。公开作品展只显示编号、课程名、课题名与链接，不显示身份表。未审核或未选择公开的作品不进作品展。

## 数据模型

- **学生**：稳定编号、所属初始班级、独立访问码。真实身份对应表仅由老师在本机保管。
- **班级**：建班时批量生成编号，后续可分配到多个课程项目。
- **课程项目**：标题、代号、类型（半天课/营期）、天数、说明；不把“6–8 天”写死。
- **课题**：属于一个项目，有顺序和营期第几天，可附起始 ZIP；支持现有零花钱模板和以后新增的通用静态网页模板。
- **参与关系**：老师可把整个班级或单独一位学生分配给项目；同一学生可参加多个项目。
- **提交版本**：学生、课题、ZIP、自动检查结果、老师反馈、预览地址、时间。
- **发布作品**：学生＋课题的当前公开网址、发布时间、是否列入作品展；历史版本保留在服务器，可由管理员手动回退。

## 老师流程

1. 创建班级并保管本地身份对照名单。
2. 创建课程项目（半天课或营期），为其添加按天排序的课题，上传每个课题的起始包。
3. 把全班或单独一位学生分配给项目；被分配学生的后台随即出现对应课题。
4. 看到提交队列，打开隔离预览，测试功能、内容与离线能力；退回修改或确认发布。
5. 需要时将作品列入/移出公开作品展；复制专属链接、显示二维码交给家长。
6. 课后把 VPS 上的原 ZIP、数据库和历史版本备份到另一处存储。

## 学生流程

1. 用长期编号和访问码登录学生后台。
2. 按项目和课题查看任务，下载老师提供的起始包，在自己电脑用 AI 制作和测试。
3. 上传整个项目 ZIP；自动检查失败立即得到原因。
4. 待审核时查看状态；收到反馈后重新提交；发布后获得专属网址和二维码。
5. 后续参加新主题或营期时继续使用同一个后台，已完成作品保留在“我的作品”。

## 发布与安全规则

- 上传码不能仅靠作品编号猜出；师生后台使用与公开作品不同的浏览器域名。学生登录使用仅限后台域名的安全 Cookie，教师密钥仅放在当前页面内存。
- ZIP 限大小、文件数、路径和静态文件类型；不执行学生后端代码。自动通过只进入待审核，老师确认后才切换公开版本。
- 公开作品使用静态文件和内容安全策略，页面中的真实账目只保存在家长的那部手机；首次联网后做离线准备。更换手机需家长自己的 JSON 备份。
- 每个学生/课题有独立作品路径；更新保留旧发布版本。若新提交被退回，家长原网址继续显示上一个通过的版本。
- 学生与家长可直接分享未列入作品展的已发布网址；作品展是否列出由老师控制。二维码和网址指向同一页面。

## 本次验收标准

1. 旧零花钱演示、旧学生链接、旧提交/发布流程仍可访问。
2. 老师创建 1 个营期、2 个课题并给一个现有学生班级分配；学生登录后能看见两课题。
3. 通用课题上传 ZIP、被退回、重交、老师预览并发布，公开作品展可见；移出作品展后专属链接仍可用。
4. 同一个学生后台能看到零花钱主题和新增主题的不同提交状态与作品链接。
5. 两种手机尺寸的浏览器可读；新作品首次联网后断网重开。真实手机添加桌面仍需现场验收。
